# Descripción de los Ejercicios 
**Ejercicio 1:** Competencia de Programación (ejercicio-1.java)
Este programa implementa la clase CompetenciaProgramacion para gestionar y evaluar las puntuaciones obtenidas por participantes en una competencia. Permite ingresar los puntajes, realizar comparaciones y calcular los resultados finales.

**Ejercicio 2:** Evaluación de Proyectos (Ejercicio2.java)
Este programa implementa la clase EvaluacionProyecto enfocada en el análisis y calificación de proyectos según criterios definidos, permitiendo procesar y mostrar la evaluación correspondiente.

# Instrucciones de Compilación y Ejecución
Para compilar y ejecutar estos programas desde la terminal (consola de comandos), asegúrarse de tener instalado el JDK de Java y seguir estos pasos según el ejercicio:

1. **Ejercicio 1** \
(ejercicio-1.java) 
+ Compilación: javac ejercicio-1.java 
* Ejecución:  java CompetenciaProgramacion
2. **Ejercicio 2** \
(Ejercicio2.java) 
* Compilación: javac Ejercicio2.java 
* Ejecución: java EvaluacionProyecto
